# Blog Project

A fully functional blog built with **Next.js 15**, **Tailwind CSS**, **Mongoose**, and **NextAuth.js**. Users can create, edit, and view posts with images and categories.

## Features
- **Create & Edit Posts**: Title, description, image upload, and categories.
- **Authentication**: Secure login with **NextAuth.js**.
- **Responsive UI**: Built with **Tailwind CSS**.
- **Error Handling**: Custom error pages with retry functionality.

## Tech Stack
- **Next.js 15** (App Router)
- **MongoDB** (via Mongoose)
- **Tailwind CSS**
- **NextAuth.js** for authentication
- **React Toastify** for notifications
